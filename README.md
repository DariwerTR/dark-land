# Cursed Lands (Проклятые Земли)

Fabric-мод для Minecraft Java Edition 1.21.11: готический проклятый биом с мёртвым лесом, некрополем, каньонами с Рекой Крови и Тёмным замком.

## Стек

- Minecraft 1.21.11
- Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11
- Loom 1.17-SNAPSHOT, Gradle 9.5.1
- Java 21, официальные маппинги Mojang

## Сборка

```
gradle build
```

Готовый jar появится в `build/libs/`. Для запуска клиента: `gradle runClient`.

Gradle wrapper пока не добавлен. Чтобы создать его, один раз выполните `gradle wrapper --gradle-version 9.5.1` и закоммитьте результат.

## Статус

- Этап 1: каркас проекта (готов).
- Этап 2: биомы `cursed_lands`, `dead_forest`, `necropolis`, `blood_canyon` (JSON датапака), блоки `blood_moss_block`, `black_wood_log`, `darkness_crystal_block`, предметы `ash`, `darkness_crystal`, `ruins_heart`, творческая вкладка (готов, ждёт проверки сборки).
- Этап 3: мёртвые деревья, пятна кровавого мха, кристаллы тьмы, измерение `cursed_lands:cursed_lands` с картой четырёх биомов (готов, ждёт проверки в игре).
- Этап 4: каньоны в горных районах измерения (низкая эрозия), заполненные до уровня моря красноватой водой биома `blood_canyon` (готов, ждёт проверки в игре).
- Этап 5: структуры `ruined_chapel` (часовня-руина), `necropolis_crypt` (склеп), `dark_castle` (Тёмный замок), сундуки с добычей (готов, ждёт проверки в игре).
- Этап 6: 18 блоков декора (готические кирпичи и их варианты, колонна, ступени/плита/стена, кровавое стекло и панель, ржавая решётка, тёмные доски, кровавый ковёр, костяная лампа, костяные кирпичи, блок пепла), рецепты, добыча, клиентская точка входа для прозрачных блоков; постройки переоформлены этими блоками (готов, ждёт проверки сборки и игры).
- Этап 7: структура `canyon_bridge` (готический мост длиной 47 блоков с опорами, арками и фонарями) в биоме `blood_canyon` (готов, ждёт проверки в игре).
- Дальше: парящие острова, ресурсы из референса.
- В самом конце: мобы (упырь, скелет-рыцарь, костяной голем, проклятый волк и остальные из референса). Они требуют больше всего работы, поэтому идут последним этапом.

Текстуры блоков и предметов временные.

## Блоки декора

Все блоки есть в творческой вкладке `Cursed Lands` и крафтятся в выживании из ванильных материалов (рецепты в `data/cursed_lands/recipe`). Готические кирпичи: 4 глубинносланцевых кирпича в квадрате или камнерез. Остальные блоки получаются из них (ступени, плита, стена, колонна, резной, потрескавшийся плавкой, с мхом вместе с блоком кровавого мха). Кровавое стекло и панель, решётка и ковёр делаются из ванильных стекла, прутьев и ковра с красителем. Прозрачные блоки подключены в `client`-точке входа `CursedLandsClient`.

## Настройка каньонов

Рельеф задан файлами в `src/main/resources/data/cursed_lands/worldgen/`:

| Файл | Что меняет |
| --- | --- |
| `noise/canyon.json` | форма и масштаб линий каньонов (`firstOctave` меньше по модулю = мельче) |
| `density_function/canyon_line.json` | ширина каньона: число `-24.0` (больше по модулю = уже) |
| `density_function/canyon_gate.json` | где каньоны разрешены: значения `-5.0` и `0.1` задают порог по эрозии |
| `density_function/canyon_cut.json` | глубина и крутизна: `-8.0` (сила) и `y_clamped_gradient` (`from_y: 44` = дно) |
| `noise_settings/cursed_lands.json` | копия ванильных настроек, изменено только `noise_router.final_density` |

Уровень моря 63, поэтому дно каньона на высоте 44 заливается водой на 19 блоков.

## Структуры

| Структура | Где появляется | Размещение |
| --- | --- | --- |
| `cursed_lands:ruined_chapel` | `cursed_lands`, `dead_forest` | каждые 14 чанков (случайно) |
| `cursed_lands:necropolis_crypt` | `necropolis` | каждые 10 чанков (случайно) |
| `cursed_lands:dark_castle` | `cursed_lands`, `dead_forest`, `necropolis` | одна штука кольцом вокруг центра измерения (около 100-250 блоков) |

Найти замок в игре: `/execute in cursed_lands:cursed_lands run locate structure cursed_lands:dark_castle`.

Постройки хранятся как шаблоны в `src/main/resources/data/cursed_lands/structure/*.nbt`. Размещение, биомы и порча камня настраиваются в `worldgen/structure`, `worldgen/structure_set`, `tags/worldgen/biome/has_structure` и `worldgen/processor_list`. Добыча: `loot_table/chests/ruins.json` и `castle.json`.

## Мост через каньон

`cursed_lands:canyon_bridge` появляется в биоме `blood_canyon` примерно каждые 8 чанков. Настройка высоты: настил лежит на высоте `start_height` + 40 блоков (сейчас 44 + 40 = 84), значение `start_height.absolute` в `worldgen/structure/canyon_bridge.json`. Если края каньонов в вашем мире выше или ниже, меняйте это число: опоры доходят до дна каньона, а концы моста упираются в склоны.
Найти: `/execute in cursed_lands:cursed_lands run locate structure cursed_lands:canyon_bridge`.

## Как попасть в измерение

Команда в игре (нужны права оператора):

```
/execute in cursed_lands:cursed_lands run spreadplayers 0 0 0 100 false @s
```
